# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of ECHO seriously. If you believe you have discovered a security vulnerability in this project (such as API key exposure, SSRF, injection vectors, or WebSocket vulnerabilities), please do **NOT** open a public issue.

Instead, please report security issues privately by:
1. Emailing the project maintainers directly at `jagtanurag22@gmail.com` or via GitHub Security Advisories.
2. Providing detailed steps to reproduce the vulnerability, including sample payloads or screenshots.

### Our Commitment
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for triage and remediation.
- Once a fix is verified, a patch will be released and credit will be given in release notes (if desired).
